# AI-Powered Synthetic Student Dataset Generator

A beginner-friendly project made with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html`: webpage structure
- `style.css`: responsive design and visual styling
- `script.js`: synthetic data generation, validation, and CSV export

## Run locally
1. Keep all three files in the same folder.
2. Double-click `index.html` to open it in your browser.
3. Choose a record count between 30 and 1,000.
4. Click **Generate dataset**.
5. Click **Validate dataset** to check data quality.
6. Click **Download CSV** to export the dataset.

No server, database, package installation, or API key is needed.

## Validation checks
Missing values, duplicate rows/IDs, field data types, and consistency of age, marks, attendance, course, student ID, name, and grade.

## Synthetic-data notice
All generated data is synthetic and is intended for software testing. It must not be treated as real student data. Randomly generated names can coincidentally match real people.
